# Paper figures

These light-theme SVGs are unchanged copies of the corresponding files in
`manuscript/figures/`. The Advanced use guide reuses the scientific figures;
it does not regenerate or change the experiments.

- `figure-2-substitution-matrix.svg`: TTN candidate substitutions and choices over ten seeded runs.
- `figure-3-morph-positions.svg`: effective alleles across five TTN morph amounts.

If a scientific figure is revised, update its manuscript source first and copy
the verified SVG here. The archived data and reproduction protocol are under
`manuscript/pilot-results/` and `manuscript/PILOT_PROTOCOL.md`.
