# Roadmap

DGW is an independent project. The priorities below are directions, not release dates or commitments.

## Next priorities

- **Reliable installation:** finish real-machine Windows testing and improve release signing and update delivery.
- **Clearer first use:** refine the examples, documentation and short workflow videos.
- **Larger projects:** extend bulk-operation benchmarks and test save, reopen and export across platforms.

## Later

- Richer gene, transcript and sequence-difference views.
- Exportable candidate comparisons for large optimizer runs.
- A tested device API with explicit permissions and isolation before enabling third-party devices.
- Morphing between samples from compatible jointly genotyped datasets.

:::note[What works today]
See the [overview](../overview.md) and [Quick Start](../usage/quickstart.md) for current features. Development history is kept separately from this roadmap.
:::
